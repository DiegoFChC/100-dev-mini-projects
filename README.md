# 🚀 100-dev-mini-projects
¡Bienvenido! Esta es una colección de miniproyectos desarrollados con HTML, CSS y JavaScript vainilla. El objetivo es fortalecer las bases del desarrollo web antes de dar el salto a frameworks complejos.

[Demo](https://100-dev-mini-projects.vercel.app/)

# 📂 Estructura del Proyecto
El repositorio está organizado de manera que cada proyecto sea independiente, facilitando su exploración y aprendizaje.

* **/:** Contiene las carpetas individuales de cada reto (HTML, CSS, JS puros).
* **/web:** Una aplicación moderna construida con Astro que sirve como interfaz para visualizar las demos en vivo de cada proyecto.

# 🕹️ Cómo empezar
Si quieres explorar los proyectos localmente o contribuir, sigue estos pasos:

1. Clonar el repositorio

```bash
git clone https://github.com/DiegoFChC/100-dev-mini-projects.git
```

2. Explorar un proyecto específico

Navega a la carpeta del proyecto que te interese y abre el archivo index.html en tu navegador.

```bash
cd nombre-del-proyecto
```

3. Ejecutar el visualizador (Astro)

Si quieres ver la plataforma web que lista todos los proyectos:

```bash
cd web
npm install
npm run dev
```
